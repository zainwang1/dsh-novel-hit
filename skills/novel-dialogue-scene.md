# 对话与场景

读者记住的是场景，不是设定。设定要通过场景给，场景要通过冲突给。

## 一、对话三个功能

每段对话至少承担一个，最好两个：

1. **推进信息**：读者或角色知道了新东西。
2. **暴露性格**：他怎么说话，比作者怎么介绍他更准。
3. **制造张力**：双方要的东西不一样，话里有压力。

只有寒暄、只有情绪、只有作者想说的解释，都是要删的对话。

## 二、删掉的开场

问好、称呼、确认对方听没听见、重复上一句、把已知信息再说一遍，全删。对话从「有分歧的那一句」开始。

原稿：—你吃了吗？—吃了。—今天怎么样？—还行，就是有点累。
改后：—你今天没去公司。—所以你查我？

## 三、潜台词

角色不直说要什么，用别的话顶。三种做法：

- **答非所问**：问「你信我吗」，答「那天你为什么先走」。
- **说一半**：话到关键处停，或者改口。
- **说反话**：明明在意的，说成不在乎，动作出卖他。

潜台词要留一个动作提示，否则读者接不到：说完把杯子放下、点了第二次烟。

## 四、用动作替代说明

说明文：他是个谨慎的人，从不轻易相信别人。
写法：他把合同翻到第三页，用指甲刮了刮油墨，才签。

说明文：她很难过。
写法：她一直看着门口，等人问，没人问，她就去洗碗了。

动作要具体到可拍。模糊的动作（「他显得很紧张」）不算动作。

## 五、场景五要素

每个场景先定五行：

```
地点：
时间：
在场者（谁，彼此什么关系）：
每个人想要什么（逐人写）：
谁挡着谁（冲突）：
```

五要素缺两个，场景就会变成人物站着聊天。

## 六、镜头与段落

- 一场戏只用一个主视角，别在两个人脑子里来回跳。
- 段落长短控制节奏：紧张用短段短句，铺陈用长段，但长段不超过七八行。
- 打斗写三样：空间位置、谁占上风、代价。招式名字不如「他被逼到柱子边，退无可退」。
- 场景转换给一个锚点：声音、光线、身体的疼痛，别用「与此同时」硬切。

## 七、日常戏不水

日常戏的作用是积累关系和埋伏笔，所以每场日常要有一件具体的小事：

- 一个人为另一个人做了一件小事，对方没说谢谢。
- 一个习惯被打破。
- 一件旧物出现。

没有小事、只有氛围的日常戏，删掉或者并进别的场景。

## 八、自检

- [ ] 每段对话是否至少有两个功能。
- [ ] 遮住名字，能不能分辨谁在说话。
- [ ] 有没有「他说道」堆满整页，能不能用动作替代。
- [ ] 场景五要素是否齐全。
- [ ] 有没有在对话里解释读者早就知道的事。
- [ ] 这一场删掉，后面会不会崩。不会崩，就删或并。
