# 黄金三章

前三章决定读者留不留。平台不同，读者耐心不同，但判断顺序一致：这一屏有事吗 → 我想知道后面吗 → 主角值得我跟着吗。

## 第一章：第一屏就要有事

**第一屏（前 200 字）**必须至少做到一件：给出冲突、给出异常、给出问题、给出结果。

七种起手式，任选其一（按题材匹配，不靠感觉）：

1. **危机中点醒**：醒来就在冲突现场，读者和主角一起缺信息。
2. **公开羞辱**：退婚、被辞、被赶出门，代价明确，围观者在场。
3. **结果先行**：先给最炸的结果，再倒回解释。
4. **数字倒计时**：只剩三天、余额只剩九块。
5. **对质**：法庭、会议室、审讯室，信息在对话里往外掉。
6. **异常日常**：生活正常到某一处不对。
7. **重生睁眼**：睁眼回到某个节点，读者立刻知道要改什么。

第一屏之后，300 到 800 字内补齐三样：

- 主角是谁，处境如何（用动作和场景交代，不用旁白）。
- 主角要什么，眼下卡在哪。
- 一个悬念或一个金手指的暗示。

**第一章末**：钩子落在问题、决定或危机上。不要落在「于是他开始了新生活」这类总结。

## 第二章：把冲突往前推一格

第二章常见错误是原地重复第一章的情绪。必须升级：

- 冲突升级：从被羞辱到被逼到具体代价（赔钱、失去资格、亲人受牵连）。
- 规则展示：主角的能力边界先给一半，别一次说透。
- 对手入场：让真正有分量的对手露一次面，或让现有对手找到靠山。
- 盟友或羁绊：至少一个人站到主角这边，读者需要情感支点。

## 第三章：给第一波完整爽点

第三章结束前，必须让读者看到一次**完整的**爽点闭环：

1. **铺垫**：所有人都认定主角不行，具体到某个人和某句话。
2. **反转**：主角用已铺垫过的信息或能力翻盘，不空降新设定。
3. **收益**：实际拿到什么——钱、位置、资格、信任、线索。
4. **反应**：对手、围观者、要人的态度变化，写出来给读者看。
5. **新的更大问题**：爽完立刻抛下一层压力，防止读者合上书。

只有反转没有收益和反应，读者会觉得「就这」。

## 逐章模板

```
章名：
本章目标（主角想做什么）：
阻碍（谁/什么挡着，强度）：
信息增量（读者本章新知道的一件事，必须真的新）：
爽点或情绪点（类型 + 位置）：
章末钩子（卡点类型）：
下章承接（读者会追问什么）：
```

## 自检表

- [ ] 第一屏有没有冲突或异常，还是先讲了三段世界观。
- [ ] 主角在前 1000 字内有没有做出至少一个选择。
- [ ] 金手指是不是第一章就解释完、后面没得挖。
- [ ] 三章内有没有出现有分量的对手，还是只打了小喽啰。
- [ ] 第一波爽点是否完整（铺垫、反转、收益、反应、新问题）。
- [ ] 每章末是不是断在问题和决定上。
- [ ] 有没有回忆大段、天气开场、主角照镜子。
- [ ] 三章读完，读者能不能用一句话说出主角要什么、谁挡着他。

## 重写开篇

原开篇数据差先别删，按顺序诊断：

1. 把前三章压缩成三句话。三句话里没有冲突，问题在结构。
2. 找第一章第一屏，看是否先给了背景。是就调到冲突之后。
3. 看第三章有没有完整爽点。没有就补，通常要删前两章的铺垫。
4. 看章末是不是总结式收尾。是就换卡点。

不提供多种版本让用户挑；给一版改好的，说明改了哪里只用一句话。
