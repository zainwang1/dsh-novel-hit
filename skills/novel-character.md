# 人设与关系网

人设不是标签，是「在压力下会怎么选」。标签可以换，选择不会。

## 一、主角三维

| 维度 | 问题 | 示例 |
|---|---|---|
| 欲望 | 他最想要什么，具体到可验证 | 不是「想变强」，是「三年内让母亲住进有电梯的房子」 |
| 缺陷 | 什么会让他在关键时刻做错 | 不信人，习惯一个人扛 |
| 底线 | 什么情况他会翻脸，越了会怎样 | 不拿孩子的命换前程 |

三维必须互相矛盾，故事才有张力：欲望逼他依赖别人，缺陷让他不敢依赖，底线决定他什么时候爆发。

## 二、能力与限制

给主角一个明确的能力，同时给一个明确的限制，否则爽点会失控：

- **能力**：金手指、专业、信息差、身份。
- **限制**：使用条件（代价、冷却、次数、场合）、被谁克制、暴露后果。

只有能力没有限制，写到三十万字就没得写；只有限制没有能力，读者看着憋屈。

## 三、成长弧

三卷各一个台阶：

- 第一卷：学会用自己的能力。
- 第二卷：发现自己能力的代价，开始为代价做选择。
- 第三卷：接受代价，做出和第一卷相反的选择。

成长不是变强。变强是数值，成长是选择变了。

## 四、配角功能表

一个配角只承担一到两个功能，功能明确，人物才立得住：

| 功能 | 作用 | 常见错误 |
|---|---|---|
| 镜像 | 和主角同一处境，选了另一条路 | 只用来夸主角 |
| 阻碍 | 挡在主角路上，动机可信 | 纯恶意工具人 |
| 导师 | 给资源和认知，但要退场 | 一直兜底 |
| 情感线 | 让主角有软肋和退路 | 只会哭与等 |
| 喜剧 | 释放压力，调节节奏 | 关键场景还在搞笑 |
| 对手 | 让主角必须成长 | 智商掉线 |

## 五、反派压迫感

有分量的反派要满足三条：

1. **动机可信**：他要的东西和主角冲突，且他自己说得通。
2. **手段有效**：他真能伤到主角，且已经伤过一次。
3. **资源在位**：他手里的东西比主角多，主角必须借力、取巧、付代价。

反派第一次出场就输，读者不会再紧张。

## 六、关系网

```
主角 —— 想保护的人（软肋）
   ├─ 盟友（互相利用 → 真交情）
   ├─ 对手（利益冲突 → 私人恩怨）
   ├─ 上级/权威（限制主角，也提供资源）
   └─ 旧人（过去留下的债）
```

每条线写三行：他们怎么认识、现在关系如何、什么会让他们反目。没写反目理由的关系线，后面写不出冲突。

## 七、人物小传模板

```
姓名：
身份与处境：
最想要（具体、可验证）：
最怕：
缺陷（关键时刻会犯的错）：
底线（越线后果）：
能力与限制：
第一次出场怎么给读者留下印象（一个动作，不是一段介绍）：
本案结束时，他会变成什么样：
```

## 八、自检

- [ ] 主角第一章有没有做出一个暴露性格的选择。
- [ ] 配角能不能用一句话说出功能。
- [ ] 反派有没有伤到过主角，且伤得有道理。
- [ ] 主要关系线有没有写反目理由。
- [ ] 人物说话有没有区分度：遮住名字，能不能认出是谁。

遮住名字认不出谁在说话，先改台词，别加旁白解释。
