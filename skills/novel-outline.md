# 长篇大纲

大纲不是故事梗概，是可执行的施工图。判断标准：换一个人拿着它，能不能接着写下去。

## 一、三层结构

```
全书（一句话卖点 + 三卷承诺）
└── 卷（一个阶段目标 + 一次大挫 + 一次翻盘）
    └── 章节卡（每章一件事 + 一个钩子）
```

全书定三卷：立身、扩张、决战。每卷必须能独立回答：这一卷主角要什么、谁挡着、卷末他失去了什么又得到了什么。

## 二、章节卡

一章一张卡，字段固定，宁可空着也不要编：

| 字段 | 要求 |
|---|---|
| 章号 / 章名 | 章名给钩子，不复述内容 |
| 本章目标 | 主角这一章想达成的一件具体事 |
| 阻碍 | 谁或什么挡着，强度要够 |
| 信息增量 | 读者本章新知道的一件事，不能是重复 |
| 爽点 / 情绪点 | 类型 + 大致位置（前中后段） |
| 章末钩子 | 卡点类型 |
| 承接 | 下章读者会追问什么 |
| 字数 | 计划字数，与平台节奏对齐 |

连续三章卡里出现「过渡」「铺垫」「交代」而没有具体事件，直接删并。

## 三、十章节拍循环

每十章一个循环，节奏不容易塌：

```
1-2 章：新目标 + 新阻碍，压期待
3-4 章：对抗升级，第一次小胜
5-6 章：对手反制，主角吃亏，暴露短板
7-8 章：主角找到新办法（新信息、新盟友、新能力）
9 章：爆发，完整爽点闭环
10 章：余韵 + 更大的问题，进入下一循环
```

循环不是死板模板，是检查表。某一环缺了，读者会在那个位置掉。

## 四、伏笔登记表

| 编号 | 伏笔 | 埋设章 | 计划回收章 | 回收方式 | 状态 |
|---|---|---|---|---|---|
| F01 | 主角旧伤 | 3 | 40 | 揭身份 | 已埋 |
| F02 | 送伞的陌生人 | 12 | 55 | 敌友反转 | 未回收 |

规则：

- 埋设与回收之间至少隔二十章，太近读者记不住也不需要记。
- 回收前两章给一次提示，让读者能自己想起来。
- 超过五十章没回收的，要么回收，要么删掉埋设。

## 五、人物出场表

| 人物 | 首次出场 | 功能 | 与主角关系 | 退场 |
|---|---|---|---|---|
| 沈鹤 | 1 | 施压者 | 上司 | 8 章撤职 |

配角一次出场只承担一个功能。同时给功能、给秘密、给感情戏的配角，读者会记混。

## 六、断章分布

把每十章按钩子类型排一遍：危机卡、决定卡、信息卡、误会卡、时间卡。同类连用不超过三章。

卷末章节必须是大卡点：真相、身份、生死、告别，四选一。

## 七、字数与平台

- 付费平台：单章 2000 到 3000 字，卷长按订阅节奏。
- 免费平台：单章 1500 到 2200 字，前 20 章节奏更密，爽点间隔更短。
- 短篇：整篇 8000 到 30000 字，开头即冲突，一到两个反转收完。

具体标准以平台要求为准，不编数字。

## 八、写到一半线乱了

1. 把已完成章节压成一页，标出每个事件改变了什么。
2. 圈出没回收的伏笔和没兑现的承诺（升级、复仇、感情）。
3. 找当前卷目标，看最近十章有没有推进它。
4. 重排后续十章：先定卷末大卡点，再倒推每章要做什么。
